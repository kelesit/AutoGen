# 功能需求与验收清单

日期：2026-09-24。依据：[业务闭环与关键步骤](../README.md)、[业务规则基线](refactor-baseline.md)。本文将已确认的业务步骤转成可开发、可验收的需求，并对照当前实现记录证据与缺口。

## 范围与验收口径

当前交付范围是本机演示：管理员发布和维护动作模板，用户选择模板、上传素材、确认报价、提交任务、取得作品，系统正确处理任务与积分。生成使用固定样片，积分不具有货币价值。

首版包含下文 FR-01 至 FR-11，以及模板维护、任务取消、管理员异常处理三个配套需求。删除作品是用户的可选操作，但删除能力及其权限、账务规则属于当前范围。收藏、发布草稿恢复作为已具备的辅助能力单列验收。

真实模型效果、真实支付、订阅、训练、用户投稿审核、创作者分成和生产容量不在本次验收范围。当前文件校验不能证明任意供应商视频都能解码播放；作品与素材列表最多展示 100 项，不承诺完整历史分页。

每项需求先描述角色、前置条件、正常流程和异常分支，再给出可观察的验收结果。编号可用于后续交互设计、开发任务和测试追踪。

| 核对标记 | 含义 |
| --- | --- |
| 自动覆盖 | 现有测试已包含该行主要断言；证据编号见文末。 |
| 待专项验收 | 已有相关代码，但尚未为该场景记录完整的专项验收结果。 |
| 待完善 | 当前实现未完成该项能力，需要后续开发；改进建议与已确认需求分开列出。 |

本轮补充 5 项有业务边界意义的自动化验收后，**44 项测试通过、构建通过**，见文末验收记录。“自动覆盖”只说明该行主要断言已由测试核对；完整页面交互另行记录。

## 按业务步骤验收

### FR-01 发布模板

**角色与前置条件：** 已登录管理员，已准备动作参考视频、独立示例成片、槽位、Prompt 和允许的输出规格。

**正常流程：** 填写模板信息 → 上传或选择自己的素材 → 配置槽位与规格 → 发布 → 在管理目录和用户广场看到模板。

**异常分支：** 必填内容不完整、素材用途或归属不符、规格无效时拒绝发布；普通用户不能调用管理接口。同一次发布重试应返回原模板。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-01.1 | 管理员发布有效模板后，普通用户能在广场找到并读取示例成片；动作参考不作为公开示例入口。 | 自动覆盖：E3 |
| AC-01.2 | 相同发布标识与内容重复提交只产生一个模板；改换内容复用标识被拒绝。 | 自动覆盖：E3 |
| AC-01.3 | 普通用户发布、修改或删除模板均被拒绝。 | 自动覆盖：E3 |
| AC-01.4 | 发布表单切换页面及刷新后恢复草稿与已上传素材引用；未上传的本地文件提示重新选择，账户之间不混用草稿。 | 待专项验收：U1；见 M1 |
| AC-01.5 | 发布时缺少必要素材、引用他人素材或配置无效，应拒绝创建模板；失败后更正内容可以重新发布。 | 自动覆盖：E5 |

### FR-02 选择模板

**角色与前置条件：** 访客或已登录用户，存在可公开使用的模板。

**正常流程：** 浏览说明和示例 → 选择模板 → 登录后进入对应创作表单，了解素材槽位与可选规格。

**异常分支：** 登录取消则不提交任务；模板下架或删除后，普通用户不能再用该模板获取新报价或创建新任务。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-02.1 | 公开模板可浏览；下架后退出公开目录和预览入口，普通用户报价被拒绝；重新上架后恢复公开展示。 | 自动覆盖：E3 |
| AC-02.2 | 未登录时选择模板，登录成功后继续打开原模板；取消登录不会自行发起创作。 | 浏览器验收：M2 |
| AC-02.3 | 收藏按账户保存，其他账户不可共享该收藏状态，重启后仍保留。 | 自动覆盖：E1 |

### FR-03 准备素材与参数

**角色与前置条件：** 已登录用户，已选定模板。

**正常流程：** 按每个必填槽位上传图片 → 查看上传结果 → 选择模板允许的时长和分辨率 → 按模板规则填写可选补充描述。

**异常分支：** 无效图片、超出限制、素材不属于本人、槽位不完整或规格不支持时阻止提交。替换图片失败后该槽位仍需重新上传，不能悄悄沿用旧图。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-03.1 | 有效图片上传后可由本人读取；伪装成图片的文件被拒绝，其他账户不能读取或引用该图片。 | 自动覆盖：E1 |
| AC-03.2 | 双人物模板按两个槽位提交后，任务保留正确的图片映射；超出允许范围的规格被拒绝。 | 自动覆盖：E3、E6 |
| AC-03.3 | 图片已上传后替换为无效或超限文件，旧图从该槽位移除；未补齐有效图片前不能提交。 | 浏览器验收：M3 |
| AC-03.4 | 缺少槽位、多余槽位、超长补充描述或模板不允许补充描述时，请求被拒绝且不创建任务。 | 自动覆盖：E2 |

输入限制沿用[模板与生成结构](motion-template.md)，不在此另设一套数值规则。

### FR-04 获取报价并确认

**角色与前置条件：** 已登录用户，已选择有效模板和规格；报价不要求先上传图片。

**正常流程：** 选择规格 → 向系统获取报价 → 展示本次积分成本 → 用户点击标有积分成本的生成按钮确认。规格变化时重新报价，最终提交携带确认金额与价格版本。

**异常分支：** 报价未取得或请求失败时不能提交；新任务缺少有效确认信息或与当前报价不一致时拒绝受理，用户取得当前报价后再次确认。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-04.1 | 当前演示的 720p、4 秒报价为 12 积分，并返回价格版本；不支持的规格无法取得报价。 | 自动覆盖：E2、E6 |
| AC-04.2 | 缺少确认金额或版本、确认信息类型无效时拒绝新任务；金额或版本不匹配时提示重新确认。任务、素材绑定、执行记录和积分流水均无新增。 | 自动覆盖：E2 |
| AC-04.3 | 用旧报价提交不同规格被拒绝；携带有效报价后可用原先被拒绝的请求标识成功提交。 | 自动覆盖：E2 |
| AC-04.4 | 连续切换规格时，晚到的旧报价不能覆盖当前选择；报价加载或失败时按钮不可提交，显示价格与提交价格一致。 | 待专项验收：U3；见 M4 |

当前后端校验报价确认字段与实际价格的一致性，不签发“已浏览报价”的凭证。报价变化后弹窗只显示错误；用户可以重新打开创作窗口获取报价。在原窗口直接刷新报价属于下文 G1 的改进建议。

### FR-05 提交并受理任务

**角色与前置条件：** 已登录用户；模板版本、素材、规格、报价有效，积分充足，未超过未结束任务数量限制。

**正常流程：** 用户提交 → 系统复核条件 → 固定模板、素材与报价 → 创建排队任务并冻结积分 → 返回可查询的任务编号。

**异常分支：** 校验失败不创建任务、不冻结积分。请求结果未知时保留原请求标识，先查原任务；相同标识与业务参数的重试返回原任务，不同业务参数复用标识被拒绝。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-05.1 | 账户有 300 积分，成功提交 12 积分任务后，可用 288、冻结 12；能查询任务和提交时的模板、素材、报价。 | 自动覆盖：E1、E2 |
| AC-05.2 | 并发重复提交同一请求只产生一个任务、一次冻结；换参数复用请求标识被拒绝。 | 自动覆盖：E1 |
| AC-05.3 | 积分不足或模板版本过期时拒绝受理；不足积分的账户余额不变且没有新任务。 | 自动覆盖：E1、E6 |
| AC-05.4 | 已受理任务即使模板随后删除，仍可按原请求标识找回；恢复不需要重新报价，不重复冻结。 | 自动覆盖：E2 |
| AC-05.5 | 同一用户已有 3 个未结束任务（含待核查）时，新任务被拒绝且无新增冻结。 | 自动覆盖：E2 |
| AC-05.6 | 浏览器丢弃提交响应后刷新，恢复提示仍存在；点击查询找回原任务，任务和冻结记录各只有一笔。 | 自动覆盖：E2；浏览器验收：M5 |

### FR-06 提交生成并确认接单

**角色与前置条件：** 系统和生成供应商，平台已受理任务并冻结积分，任务具备执行条件。

**正常流程：** 系统取出排队任务 → 按固定配置向供应商提交 → 确认接单并保存供应商任务编号 → 进入生成阶段。

**异常分支：** 接单响应不确定时先查原任务；明确未接单的限流可以等待重试；不能可靠查单时进入人工核查，保留冻结，禁止自动重新生成或释放积分。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-06.1 | 接单成功但响应丢失时，查回同一个供应商任务；最终只有一次生成提交、一次结算。 | 自动覆盖：E2 |
| AC-06.2 | 不支持可靠查单时停止自动执行，任务进入待核查、积分保持冻结；取消或无依据恢复被拒绝。 | 自动覆盖：E2 |
| AC-06.3 | 明确被限流后暂停新提交并等待；多个执行器共同运行时，全局最多 2 个任务占用提交/生成名额。 | 自动覆盖：E2 |
| AC-06.4 | 执行进程在供应商接单后退出，恢复时找到原外部任务，不产生第二次生成。 | 自动覆盖：E2 |

这些验收使用有明确幂等与查单能力的本地模拟供应商；真实供应商必须按实际协议重新验证。

### FR-07 执行生成并取得结果

**角色与前置条件：** 供应商、系统和查询进度的用户，供应商已经接单。

**正常流程：** 供应商执行 → 系统跟踪进度 → 确认生成成功并取得结果信息 → 任务进入保存阶段，积分继续冻结。

**异常分支：** 确认生成失败则结束任务并释放积分；状态未知或超过等待上限则核查；晚到或重复结果不能使任务状态回退或重复记账。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-07.1 | 供应商生成成功但文件尚未保存时，任务处于保存阶段，尚未结算。 | 自动覆盖：E2 |
| AC-07.2 | 确认生成失败后释放冻结积分一次；已发生的供应商模拟成本继续保留。 | 自动覆盖：E1、E2 |
| AC-07.3 | 已完成任务收到重复成功或晚到的处理中事件，状态不回退，账务不重复变化。 | 自动覆盖：E2 |
| AC-07.4 | 轮询持续返回处理中，且距供应商确认接单已超过当前 3 分钟等待上限时，转入核查并保留冻结；排队超过 3 分钟后才接单的任务不立即转入核查。 | 自动覆盖：E2 |

当前 3 分钟计时从供应商确认接单开始，不包含排队时间；属于演示策略，不是对真实生成时长的服务承诺。

### FR-08 保存并校验结果

**角色与前置条件：** 系统，已经取得供应商生成结果。

**正常流程：** 获取结果文件 → 执行当前文件检查 → 保存到受控存储 → 提供可用于交付的结果记录。

**异常分支：** 保存失败优先重试原结果，不重新生成；重试预算耗尽则转入人工核查。保存期间继续冻结积分，不能提前宣称已交付。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-08.1 | 首次保存失败时，重试保存原结果；最终一份作品、一次结算，供应商生成只提交一次。 | 自动覆盖：E2 |
| AC-08.2 | 保存重试耗尽时转入待核查并保持冻结；管理员恢复后从保存阶段继续。 | 自动覆盖：E2 |
| AC-08.3 | 文件已落盘但交付与账务尚未完成时进程退出，重新运行后恢复交付，不重复生成或结算。 | 自动覆盖：E2 |

当前只用固定样片验证基本格式、体积和落盘流程。完整视频解析、转码及真实网络下载边界列入真实接入阶段，不以“文件保存成功”证明任意视频可播放。

### FR-09 交付作品并结算

**角色与前置条件：** 系统，输出文件已保存并通过当前校验。

**正常流程：** 建立归属于用户的作品 → 完成任务 → 将冻结积分结算为消耗 → 用户能在作品库取得播放和下载入口。以上业务结果保持一致。

**异常分支：** 交付尚未完成则继续恢复，不提前结算；重复完成事件不能建立重复作品或产生第二笔结算。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-09.1 | 正常任务完成后有对应作品，作品关联原任务与模板版本，所有者可以读取和下载样片。 | 自动覆盖：E3、E6 |
| AC-09.2 | 300 积分账户的 12 积分任务交付后，可用 288、冻结 0；同一任务只有一笔结算，无需等待用户首次播放。 | 自动覆盖：E1、E2 |
| AC-09.3 | 重复结果、保存重试或保存后进程退出均不增加第二份作品和第二笔结算。 | 自动覆盖：E2 |

### FR-10 查看与使用作品

**角色与前置条件：** 已登录用户，拥有任务记录或已交付作品。

**正常流程：** 进入作品库 → 分别查看处理中、待核查、失败或已交付结果 → 查看任务详情与积分流水 → 播放或下载自己的作品。

**异常分支：** 未登录或非所有者不能取得私人作品；管理员查看任务记录的权限不自动赋予用户作品的读取权限。进行中或失败任务不能冒充已交付作品。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-10.1 | 所有者能读取及下载作品；未登录、其他用户和非所有者管理员不能通过作品入口取得文件。 | 自动覆盖：E1、E3 |
| AC-10.2 | 用户可用积分等于其积分流水累计，冻结积分等于未结算任务的冻结总额；应用重启后账户、任务与流水保留。 | 自动覆盖：E1、E2 |
| AC-10.3 | 页面能区分任务状态与作品结果，固定样片在浏览器中可实际播放，下载可用，操作不再次扣分。 | 待专项验收：U2、U7；见 M6 |
| AC-10.4 | 待核查任务单独筛选并明确显示已暂停、积分仍冻结，不显示为持续生成动画；计数与处理中任务分开。 | 接口计数自动覆盖：E2；页面待专项验收：U2 |

列表当前最多展示 100 项，计数使用全量数据。完整历史分页列为后续扩展 G2，不将现有列表视为无限历史检索能力。

### FR-11 删除作品（用户可选）

**角色与前置条件：** 已登录作品所有者，作品已交付。

**正常流程：** 选择删除 → 明确确认不可恢复 → 作品退出列表 → 后续播放和下载请求被拒绝 → 系统清理无有效占用的文件。

**异常分支：** 非所有者删除被拒绝；重复删除不重复改变账务；物理文件删除失败可以重试，但不能恢复作品访问权限。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-11.1 | 删除自己的作品后列表不再返回该作品，新的播放与下载请求被拒绝，旧任务视频入口也不能绕过。 | 自动覆盖：E3、E4 |
| AC-11.2 | 删除及重复删除均保留任务完成事实和原积分记录，不退款；他人删除被拒绝。 | 自动覆盖：E4 |
| AC-11.3 | 文件清理失败后仍拒绝访问，随后可重试清理；晚到成功事件不能复活作品。 | 自动覆盖：E4 |
| AC-11.4 | 页面删除前提示不可恢复；取消确认保留作品，确认删除后列表与操作入口同步更新。 | 待专项验收：U2；见 M6 |

撤销访问针对新的请求，不回收已下载副本，也不保证中断已开始的传输或浏览器缓冲。

## 配套业务需求

### FR-12 维护模板与素材

**角色与前置条件：** 已登录管理员，具有可维护的模板或自己的素材。

**正常流程：** 查询目录 → 修改配置、上下架或确认删除 → 按规则生成新版本或更新展示信息；无占用的素材可以显式删除。

**异常分支：** 并发修改使用过期版本时拒绝覆盖；素材仍被模板或未结束任务占用时拒绝删除；已删除模板不能恢复为可用模板。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-12.1 | 目录可搜索、筛选和分页；修改生成配置形成新版本，单独改标题不改变生成版本，历史任务保留原配置。 | 自动覆盖：E3、E5 |
| AC-12.2 | 过期修改或删除被拒绝；删除模板退出广场，已有任务的素材引用及既有作品继续有效。 | 自动覆盖：E3、E4、E5 |
| AC-12.3 | 共享素材有任何有效占用时不能删除；解除全部占用后才能清理，过期但仍被活动任务使用的图片继续保留。 | 自动覆盖：E4 |

### FR-13 取消尚未提交的任务

**角色与前置条件：** 已登录任务所有者，任务仍处于允许取消的排队阶段。

**正常流程：** 用户取消 → 系统确认尚未向供应商提交 → 结束任务并释放冻结积分。

**异常分支：** 非所有者、已提交或待核查任务不能以用户取消直接释放积分；重复取消已取消任务返回原结果。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-13.1 | 取消排队任务释放冻结一次，重复取消余额不再变化；其他用户不能取消该任务。 | 自动覆盖：E1 |
| AC-13.2 | 接单结果无法查明的待核查任务取消被拒绝，冻结积分保留。 | 自动覆盖：E2 |
| AC-13.3 | 用户取消与系统开始提交同时发生时，只能有一个合法结果：取消并释放，或已提交且拒绝取消；不能既执行又释放。 | 自动覆盖：E2；在并发交错下核对了任务终态和积分流水 |

### FR-14 查看异常并恢复处理

**角色与前置条件：** 已登录管理员，存在异常或待核查任务。

**正常流程：** 查看任务阶段、调用记录、积分和错误 → 判断能否安全恢复 → 从原阶段继续 → 保留管理员操作记录。

**异常分支：** 普通用户不能操作恢复；没有可靠证据时保留待核查，不能通过“恢复”盲目重新生成或强制释放积分。

| 验收编号 | 场景与预期结果 | 当前核对 |
| --- | --- | --- |
| AC-14.1 | 保存重试耗尽后，普通用户恢复被拒绝；管理员恢复原保存阶段后完成交付，时间线记录操作。 | 自动覆盖：E2 |
| AC-14.2 | 供应商无可靠查单能力时，管理员恢复仍被拒绝，任务保持待核查、积分保持冻结。 | 自动覆盖：E2 |
| AC-14.3 | 后台能查看执行器在线情况、并发上限、暂停提交和待核查数量；展示值与任务记录相符。 | 接口自动覆盖在线状态、并发上限和待核查数量：E2；页面与暂停提示待专项验收：U2、U6 |

无证据任务的完整人工对账、处理时限和最终处置不在当前演示中实现；真实接入前需确定供应商证据渠道及处理流程。
