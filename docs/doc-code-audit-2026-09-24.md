## 代码侧仍存在的缺口

这些是核对中发现的现状，不通过修改文档声称已经实现或修复。

1. **已清理：已删除模板详情的失效播放器。** 当前 [CatalogManager](../src/CatalogManager.tsx) 在 deleted 状态仅展示配置和提示，不渲染媒体播放器。参考视频路由仍按管理员身份、当前版本引用和资产 ready 校验；其权限语义未在清理中变更。
2. **报价确认不是后端必填条件。** [GenerationService](../server/generation-service.mjs) 接受缺少报价确认字段的请求；若业务要求“用户必须确认当前价格”，需修改接口校验及测试。现有前端会携带这些字段，不等于 API 已强制执行。
3. **模板 Prompt 不对生成用户保密。** [Engine 的 templateSnapshot](../server/engine.mjs) 和 [任务序列化](../server/app.mjs) 返回完整配置。若以后要求模板配方保密，需拆分内部执行快照和用户任务响应，不能只隐藏广场字段。
4. **列表尚非完整分页能力。** [CollectionService](../server/collection-service.mjs) 和 [AssetService.list](../server/asset-service.mjs) 使用 LIMIT 100；老作品或老素材可能无法从界面访问。管理模板目录已有分页，不代表其他列表也有。
5. **已清理：旧兼容分支与宽松模板类型。** optional-image 快照兜底、simulateFailure 别名、未使用的 Creation/fps 类型、旧 getCustom 命名已移除。前端明确区分公开模板、管理员模板和任务快照，必填版本、槽位、输出配置不再用虚构默认值兜底。
