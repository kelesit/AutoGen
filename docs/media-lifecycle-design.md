# 媒体生命周期（重构后实现）

2026-09-24。详细业务范围见 refactor-baseline.md。本文件描述已实现行为。

## 文件身份与关联

图片、动作参考、示例视频和生成输出统一记录在 assets，实际字节保存于 DATA_DIR/assets。id 对应不可变内容；filename 由服务端生成。kind 表示用途 image/reference/preview/output；不跨用户去重。

资产状态为 staging（写入未完成）、ready（可绑定/读取）、deleting（撤销读取、等待物理清理）、deleted（文件已清理）。元数据保留身份、归属、类型、大小、SHA-256、时间及清理错误。图片经解码和重编码；视频目前仅基本 MIME/头部/大小校验，完整媒体探测待补，不把校验不足伪装成支持。

结构化外键关联：template_version_assets、templates.preview_asset_id、job_input_assets、job_outputs、creations.asset_id。JSON 快照负责追溯当时配置，不再作为文件占用检查的唯一依据。

有效保留根：

- 未删除模板的当前版本参考和当前预览（包括下架模板）。
- 未结束任务的输入和已保存待提交的输出，包括 needs_review。
- 未删除作品的成片。
- 管理员素材库中 ready 的参考/预览。
- 上传宽限期内的临时图片或正在写入的资产。

已结束任务及旧版本的历史关联不阻止物理清理。删除模板不可恢复，因而无需为了恢复永久保留其文件；不过仍在素材库中的上传会继续保留，需用户显式删除。

## 上传、替换与读取

先登记 staging，写临时文件，fsync、rename，标记 ready。进程中断后有元数据可查，超期 staging 可清理；任务输出存在活动执行关联则继续保留。输出 ID 对任务稳定，崩溃恢复不改变文件内容，SHA 不同则拒绝覆盖。

替换创建新资产，模板配置创建新版本；任务永远使用提交时固定的关系。绑定校验在同一数据库事务内完成，清理不能在存在检查与绑定之间插入。

读取按业务入口授权：用户图片要求所有者；模板参考要求管理员及当前模板引用；公开模板只公开示例；作品要求所有者、作品未删除、资产 ready。无通用公开资产下载入口。前端作品卡片使用视频预览，不再依赖用户输入图作封面。

## 删除

- 作品：所有者操作，确认后不可恢复。作品的 deleted_at 立即阻止列表/计数及后续播放/下载请求；任务与流水保持，费用不退款。它不会中断已经打开的下载流，也不能回收浏览器已经缓冲的视频。资产此时可能仍为 ready，待 Worker 检查到无占用后标记 deleting 并清理；访问撤销由作品权限入口实现。不存在旧任务视频回退接口。元数据删除标记用于幂等与避免复活，不提供回收站。
- 模板：不可恢复删除，退出目录；未结束任务继续持有旧参考。
- 上传素材：所有者可以删除无当前模板/未结束任务引用的非输出资产；有引用返回 409。输出仅能通过作品删除。
- 临时图片：从上传时起 24 小时后具备自动清理资格；排队、执行和待核查任务仍会保护输入。任务结束后仍需同时满足到期和无其他占用才会自动清理，不承诺长期保存原图。`expires_at` 是清理时间条件，读取/绑定只检查 ready 等条件；到期但 Worker 尚未清理的图片仍可能被使用。
- 当前预览为独立上传资产，不支持作品转预览；所以不会出现用户删除个人作品后模板仍公开同一资产的隐式关系。用户手动重新上传同一段视频会得到另一个资产 ID，两者独立管理。

## 后台清理

Worker 每轮检查一批候选。事务内排除有效保留根，标记 deleting；新增引用只接受 ready。随后删除文件和临时文件：不存在视为成功，其余错误记录并重试；成功标记 deleted。多个 Worker 重复执行安全。

候选查询先排除被引用资产再限制批量数，防止前面的保留资产阻塞后面的可清理文件。已删除作品立即停止访问，物理清理失败不会重新开放。Worker 离线时清理等待上线，不假装文件已经清除。

不提供无依据的磁盘全盘扫描删除；所有本应用新写文件都先登记资产。公共内置样片仅为 mock 输入源，不在用户清理范围。已下载副本、未来 CDN/远端模型副本、备份恢复的删除语义需要各自的协议，本地删除不涵盖它们。

## 验证

测试覆盖共享参考、多模板占用、旧任务版本保护、图片宽限期、素材库保留、删除失败重试、拒绝绑定 deleting、重复作品删除、任务与账务不变、晚到事件不复活作品，以及从所有旧/新播放入口验证访问撤销。
